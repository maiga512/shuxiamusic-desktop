# Sidecar Runtime

Generated by `scripts/prepare-sidecar-runtime.mjs`.

Contains:
- portable Node used by packaged Tauri builds
- npm packages required by `sidecar/` (`axios`, `iconv-lite`, ...)

Do not commit downloaded Node binaries. Prepare before packaging:

```bash
npm run sidecar:prepare-runtime
# Windows x64 explicitly:
npm run sidecar:prepare-runtime -- --platform win32 --arch x64
```
